about=FeatureNavEd is a dockable panel that lets you navigate and edit features of a vector layer one by one, similar to the Identify tool but with full navigation and editing control.
    <br><br>
    <b>Layer Selection</b> — Select a vector layer from the dropdown or drag-and-drop directly from the Layers panel. Supports all vector layer types (point, line, polygon).
    <b>Feature Navigation</b> — Step through features with First, Previous, Next, and Last buttons. Sort features by any field in ascending or descending order. Each feature is automatically selected and zoomed to.
    <b>Lock Navigation</b> — Keep the navigator on its feature while you click and select other things on the map; the locked feature is outlined on the canvas.
    <b>Attribute Form</b> — Displays the native QGIS attribute form for each feature. Supports inline editing when the layer is in edit mode.
    <b>Multi-Edit</b> — Select 2 or more features while in edit mode to set shared attribute values. Nothing is written until you click Apply, and the form fits narrow panels.
    <b>Editing Toolbar</b> — Toggle editing, save, undo and redo on the navigated layer, whichever layer is active in the Layers panel.
    <b>Always in Sync</b> — Features deleted, added, undone, saved or rolled back anywhere in QGIS are reflected in the navigation list.
    <b>Field Organizer</b> — Hide the fields you don't need (per layer, saved with the project) to keep long forms short.
    <b>Query Builder</b> — Filter the layer and navigate only the matching features.
    <b>Find</b> — Search for features by field value with an autocomplete dropdown, without filtering the navigation list.
    <b>Auto-zoom</b> — Configurable map scale control adjusts the zoom level when navigating between features.
